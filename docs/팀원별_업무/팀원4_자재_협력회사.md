# 팀원 4 — 자재·협력회사 파트

## 담당 목표

협력회사가 견적·제작·출하 정보를 입력하게 하고, 자재부서에서 입고·재고·출고·반품을 처리한다.

- 담당 브랜치: `feature/material-supplier`
- 담당 패키지: `material`, `supplier`
- 담당 화면: 협력회사 견적·발주·제작·출하, 입고, 재고, 출고, 반품, 거래명세서

## 다른 팀원에게 제공할 핵심 데이터

- 협력회사 견적금액과 납기
- 발주 확인 여부
- 계약조건 확인 여부
- 제작·출하 상태
- 진척검수 보완 처리 결과
- 출하 품목과 수량
- 입고 결과
- 품목별 현재고
- 자재 출고 결과
- 반품과 재출하 결과

## 1주차 — 협력회사·재고 기본 화면

### 해야 할 일

- 자재·협력회사 패키지와 JSP 폴더 만들기
- 출하, 입고, 재고, 출고, 반품 테이블 확인
- 테스트용 발주와 재고 데이터 준비
- 협력회사 발주 목록 조회
- 자재 재고 목록 조회
- 자재·협력회사 메뉴 이동 확인

### 필요한 지원

- 팀원 1에게 협력회사 계정과 `vendorId`를 받는다.
- 팀원 2와 품목 번호 연결 방식을 합의한다.
- 팀원 3과 견적·발주·출하 상태값을 합의한다.

### 완료 기준

- 협력회사 발주와 자재 재고 목록이 조회된다.
- 품목 번호, 회사 번호, 발주 번호 연결 방식이 확정된다.
- 자재부서와 협력회사 메뉴가 열린다.

## 2주차 — 협력회사와 자재 CRUD

### 협력회사 기능

- 견적 요청 조회와 견적 제출
- 발주 상세 조회와 발주 확인
- 계약조건 확인
- 진척검수 일정 조회와 보완사항 처리
- 제작 상태 변경
- 출하 등록
- 거래명세서 정보 등록

### 자재부서 기능

- 재고 기본정보 등록·수정
- 입고 예정 목록
- 입고 상세와 검수
- 재고 조정 내역 조회
- 수량과 날짜 입력 검사

### 완료 기준

- 테스트용 견적 요청에 견적을 제출할 수 있다.
- 테스트용 발주를 확인하고 출하할 수 있다.
- 출하 건을 입고 처리하면 재고가 증가한다.

## 3주차 — 구매·생산 파트 연결

### 해야 할 일

- 팀원 3의 견적 요청을 협력회사별로 조회
- 견적금액과 납기를 구매부서에 전달
- 구매 발주 확인과 제작 상태 변경
- 출하 정보를 구매·자재부서에 전달
- 출하 건을 입고 예정으로 생성
- 입고 완료 시 품목 재고 증가
- 구매부서에 입고 완료·반품 상태 API 신호 전달
- 팀원 2의 불출 요청 조회

### 팀원별 연결

| 연결 팀원 | 주고받을 내용 |
|---|---|
| 팀원 1 | 협력회사 계정, 회사별 조회 제한, 자재부서 권한 |
| 팀원 2 | 현재고 제공, 불출 요청 수신, 출고 결과 전달 |
| 팀원 3 | 견적 요청 수신, 견적 제출, 발주 수신, 출하 상태 전달 |

### 완료 기준

- 협력회사가 자기 회사의 요청만 조회한다.
- 구매 발주에서 출하와 입고까지 연결된다.
- 생산부서가 현재고를 조회할 수 있다.
- 자재부서가 생산 불출 요청을 조회한다.

## 4주차 — 출고·반품과 통합 테스트

### 해야 할 일

- 생산 불출 요청 승인과 자재 출고
- 출고 완료 시 재고 감소
- 입고 불량과 반품 등록
- 협력회사 반품 확인과 보완 처리
- 협력회사 재출하
- 자재부서 재입고 검수
- 재고 부족, 과다 출고, 중복 입고 방지
- 전체 업무 시나리오 테스트
- 발표에서 견적 제출→출하→입고→재고 흐름 준비

### 완료 기준

- 입고하면 재고가 증가하고 출고하면 감소한다.
- 보유 재고보다 많은 수량은 출고되지 않는다.
- 반품부터 재출하·재입고까지 연결된다.
- 다른 협력회사의 데이터는 조회되지 않는다.
- 테스트와 서버 실행에 성공한다.

## Git 작업 규칙

```text
작업 시작: Pull → feature/material-supplier 확인
작업 종료: 테스트 → material·supplier 파일만 Stage → Commit → Push
병합 요청: 최신 main 반영 → 재고 수량 테스트 → Pull Request
```

재고 수량이 바뀌는 입고·출고·반품 처리는 중복 실행되지 않는지 반드시 확인한다.
