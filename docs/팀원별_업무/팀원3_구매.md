# 팀원 3 — 구매 파트

## 담당 목표

생산부서의 부족 자재를 조달계획으로 만들고 협력회사 견적과 구매 발주를 관리한다.

- 담당 브랜치: `feature/purchase`
- 담당 패키지: `purchase`
- 담당 화면: 구매 현황, 조달계획, 견적 관리, 계약 관리, 구매 발주, 진척검수, 발주 마감, 연계 조회

## 다른 팀원에게 제공할 핵심 데이터

- 조달계획 번호
- 견적 요청 번호
- 견적 품목·수량·마감일
- 선정 협력회사
- 확정 거래조건과 계약 번호
- 구매 발주 번호
- 발주 수량과 요구 납기일
- 발주 진행 상태
- 검수 일정·평가·보완사항·납기 진도율

## 1주차 — 구매 기본 화면

### 해야 할 일

- 구매 패키지와 JSP 폴더 만들기
- 조달계획, 견적 요청, 견적 제출, 발주 테이블 확인
- 테스트용 부족 자재 데이터 준비
- 조달계획 목록 조회
- 구매 현황 기본 화면
- 구매부서 메뉴 이동 확인

### 필요한 지원

- 팀원 1에게 구매 테스트 계정과 협력회사 기본정보를 받는다.
- 팀원 2와 부족 자재 전달 컬럼을 합의한다.
- 팀원 4와 발주·출하 상태값을 합의한다.

### 완료 기준

- 테스트 데이터로 조달계획 목록이 표시된다.
- 견적과 발주에서 사용할 번호 및 상태값이 확정된다.
- 구매부서 메뉴가 정상적으로 열린다.

## 2주차 — 조달·견적·계약·발주 CRUD

### 해야 할 일

- 조달계획 등록·상세·수정
- 견적 요청 등록·상세·수정
- 협력회사별 견적 목록과 비교 화면
- 업체 선정 처리
- 거래조건 확정과 계약 등록
- 계약 기준 거래명세서 준비정보 생성
- 구매 발주 등록·상세·수정
- 금액, 수량, 마감일, 납기일 입력 검사
- 견적과 발주 상태 변경

### 기본 상태 예시

```text
견적: 요청 → 제출 → 마감 → 선정
발주: 작성 → 발주 → 확인 → 제작 → 출하 → 입고완료
```

### 완료 기준

- 테스트 데이터로 견적 요청부터 계약·발주까지 진행된다.
- 여러 협력회사의 단가와 납기를 비교할 수 있다.
- 선정된 협력회사에만 발주를 생성한다.

## 3주차 — 생산·협력회사·자재 연결

### 해야 할 일

- 팀원 2의 부족 자재를 조달계획으로 가져오기
- 생산계획 번호와 구매 요청 연결
- 협력회사에 견적 요청 공개
- 협력회사가 제출한 견적 조회
- 확정 견적의 계약조건을 협력회사에 통보
- 선정 업체에 구매 발주 전달
- 진척검수 일정 등록
- 제작 진척·납기 진도 평가와 보완사항 등록
- 납기 진도율 확인
- 협력회사의 제작·출하 상태 조회
- 자재부서 입고 완료 API 신호 조회

### 팀원별 연결

| 연결 팀원 | 주고받을 내용 |
|---|---|
| 팀원 1 | 구매부서 권한, 협력회사 번호 |
| 팀원 2 | 생산계획, 부족 자재·수량, 필요일 |
| 팀원 4 | 견적 제출, 발주 확인, 제작·출하, 입고 결과 |

### 완료 기준

- 생산부서가 전달한 부족 자재로 조달계획을 생성한다.
- 협력회사는 자기 회사의 요청만 조회한다.
- 협력회사 출하 상태가 구매 진척 화면에 보인다.
- 자재 입고 완료 신호가 발주 마감 조건에 연결된다.

## 4주차 — 진척 관리와 통합 테스트

### 해야 할 일

- 납기 임박 발주 조회
- 입고와 반품 결과 연계 조회
- 정상 입고 완료 후 발주 마감
- 기간별 발주 진행 현황 리포트
- 잘못된 금액·수량·날짜 예외 처리
- 구매부서만 견적 요청과 발주를 수정하도록 확인
- 전체 업무 시나리오 테스트
- 발표에서 부족 자재→견적→발주 흐름 준비

### 완료 기준

- 조달계획부터 입고 결과까지 연결된다.
- 발주별 현재 진행 상태를 확인할 수 있다.
- 다른 부서는 구매 발주를 수정할 수 없다.
- 테스트와 서버 실행에 성공한다.

## Git 작업 규칙

```text
작업 시작: Pull → feature/purchase 확인
작업 종료: 테스트 → purchase 파일만 Stage → Commit → Push
병합 요청: 최신 main 반영 → 발주 흐름 테스트 → Pull Request
```

생산·협력회사 테이블을 독자적으로 새로 만들지 말고 합의된 외래키로 연결한다.
