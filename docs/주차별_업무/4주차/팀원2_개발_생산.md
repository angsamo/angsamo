# 4주차 — 팀원 2 개발·생산

## 이번 주 목표

자재 수령과 생산 진행을 완성하고 전체 업무 흐름을 테스트한다.

## 해야 할 일

- 자재부서 출고 결과 확인
- 자재 수령 상태 변경
- 생산 진행 상태 변경
- 수량 부족과 잘못된 날짜 예외 처리
- 다른 부서의 품목·BOM 수정 차단 확인
- 전체 시나리오 통합 테스트
- 발표용 품목→BOM→생산계획 흐름 준비
