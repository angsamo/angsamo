# 4주차 — 팀원 4 자재·협력회사

## 이번 주 목표

자재 출고와 반품·재출하 흐름을 완성하고 재고 오류를 방지한다.

## 해야 할 일

- 생산 불출 요청 승인과 자재 출고
- 출고 완료 시 재고 감소
- 입고 불량과 반품 등록
- 협력회사 반품 확인과 보완
- 협력회사 재출하
- 자재부서 재입고 검수
- 재고 부족·과다 출고·중복 입고 방지
- 전체 시나리오 통합 테스트
- 발표용 견적→출하→입고→재고 흐름 준비

## 완료 기준

- [ ] 입고 시 재고가 증가하고 출고 시 감소한다.
- [ ] 보유 재고보다 많이 출고되지 않는다.
- [ ] 반품→재출하→재입고가 연결된다.
- [ ] 다른 협력회사 데이터가 조회되지 않는다.
- [ ] 최종 Pull Request가 병합됐다.
