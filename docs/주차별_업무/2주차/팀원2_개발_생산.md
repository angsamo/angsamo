# 2주차 — 팀원 2 개발·생산

## 이번 주 목표

품목·BOM·생산계획 CRUD와 자재 소요량 계산을 완성한다.

## 해야 할 일

- 품목 등록·수정·상태 변경
- BOM 등록·수정·삭제
- 생산계획 등록·상세·수정
- 생산 품목과 수량 입력 검사
- 생산 진행 상태 변경
- 품목과 BOM 검색
- 자재 소요량 계산

## 계산 규칙

```text
필요 자재 수량 = BOM 기준 수량 × 생산 수량
```

## 완료 기준

- [ ] 품목과 BOM CRUD가 동작한다.
- [ ] 생산계획에서 품목을 선택할 수 있다.
- [ ] 생산 수량에 따라 자재 소요량이 계산된다.
- [ ] 잘못된 수량은 등록되지 않는다.
- [ ] CRUD 테스트 후 Pull Request를 만들었다.
