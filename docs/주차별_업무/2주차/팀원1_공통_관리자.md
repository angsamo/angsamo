# 2주차 — 팀원 1 공통·관리자

## 이번 주 목표

관리자 CRUD와 기본 로그인 기능을 완성한다.

## 해야 할 일

- 사용자 등록·상세·수정·사용 중지
- 부서 등록·상세·수정·사용 중지
- 협력회사 기본정보 등록·상세·수정
- 사용자·부서 검색
- 필수 입력값 검사
- 간단한 로그인 처리
- 로그인한 사용자 정보를 세션에 저장
- 일반 사용자의 관리자 URL 접근 차단

## 주의 사항

- 사용자를 실제 삭제하지 말고 사용 상태를 변경한다.
- 비밀번호와 DB 접속 정보를 GitHub에 올리지 않는다.
- 공통 JSP·CSS·설정 파일 변경은 팀원들에게 알린다.

## 완료 기준

- [ ] 관리자가 사용자와 부서를 관리한다.
- [ ] 협력회사 계정에 회사 번호가 연결된다.
- [ ] 일반 사용자는 관리자 화면에 접근할 수 없다.
- [ ] CRUD 테스트 후 Pull Request를 만들었다.
