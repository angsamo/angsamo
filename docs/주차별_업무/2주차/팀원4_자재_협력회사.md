# 2주차 — 팀원 4 자재·협력회사

## 이번 주 목표

협력회사 견적·출하와 자재 입고·재고 기본 기능을 완성한다.

## 협력회사 작업

- 견적 요청 조회와 견적 제출
- 발주 상세 조회와 발주 확인
- 계약조건 확인
- 진척검수 일정 조회와 보완사항 처리
- 제작 상태 변경
- 출하 등록
- 거래명세서 정보 등록

## 자재부서 작업

- 재고 기본정보 등록·수정
- 입고 예정 목록 조회
- 입고 상세와 검수
- 입고 완료 시 재고 증가
- 재고 조정 내역 조회
- 수량과 날짜 입력 검사

## 완료 기준

- [ ] 테스트 견적 요청에 견적을 제출한다.
- [ ] 발주를 확인하고 출하할 수 있다.
- [ ] 출하 건을 입고 처리하면 재고가 증가한다.
- [ ] 중복 입고가 발생하지 않는다.
- [ ] CRUD 테스트 후 Pull Request를 만들었다.
