# 1주차 — 팀원 1 공통·관리자

## 이번 주 목표

모든 팀원이 사용할 공통 프로젝트 구조와 사용자·부서 기반을 준비한다.

## 해야 할 일

- `feature/admin` 브랜치 생성
- `common`, `admin` 패키지 구성
- Spring Boot와 MySQL 연결 확인
- 부서·사용자·협력회사 기본 테이블 확인
- 테스트 관리자와 부서별 사용자 데이터 생성
- 공통 헤더와 사이드바 정리
- 로그인 사용자 정보를 임시 세션에 저장
- 사용자·부서 목록 조회 화면 구현

## 팀원에게 전달할 정보

- `userId`, `departmentCode`, `role`, `vendorId` 형식
- 부서 코드: `ADMIN`, `DEVELOPMENT`, `PRODUCTION`, `PURCHASE`, `MATERIAL`, `SUPPLIER`
- 역할 코드: `MASTER`, `DEPARTMENT_MANAGER`, `WORKER`, `SUPPLIER`
- 부서 간 공유 방식: 승인 워크플로우, 공유 대시보드, 자동 API
- 테스트 계정 정보
- 공통 화면 사용 방법

## 완료 기준

- [ ] Spring Boot와 MySQL이 연결된다.
- [ ] 테스트 사용자의 부서 정보를 조회할 수 있다.
- [ ] 공통 헤더와 사이드바가 표시된다.
- [ ] 모든 부서의 기본 메뉴가 열린다.
- [ ] 변경 내용을 Commit하고 Push했다.
