# 3주차 — 팀원 4 자재·협력회사

## 이번 주 목표

구매부서 발주를 협력회사 출하와 자재부서 입고·재고로 연결한다.

## 해야 할 일

- 견적 요청을 협력회사별로 조회
- 견적금액과 납기를 구매부서에 전달
- 구매 발주 확인과 제작 상태 변경
- 계약조건 확인과 진척검수 보완사항 처리
- 출하 정보를 구매·자재부서에 전달
- 출하 건을 입고 예정으로 생성
- 입고 완료 시 품목 재고 증가
- 입고 완료·반품 결과를 구매부서 API 신호로 전달
- 생산부서의 불출 요청 조회

## 연결 대상

- 팀원 1: 협력회사 계정과 회사별 조회 제한
- 팀원 2: 현재고 제공과 불출 요청 수신
- 팀원 3: 견적 요청, 발주, 제작·출하 상태

## 완료 기준

- [ ] 협력회사는 자기 회사 요청만 조회한다.
- [ ] 발주에서 출하와 입고까지 연결된다.
- [ ] 생산부서가 현재고를 조회한다.
- [ ] 자재부서가 불출 요청을 조회한다.
