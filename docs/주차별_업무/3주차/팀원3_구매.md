# 3주차 — 팀원 3 구매

## 이번 주 목표

생산부서의 부족 자재를 협력회사 견적·발주·출하 흐름으로 연결한다.

## 해야 할 일

- 생산 부족 자재를 조달계획으로 가져오기
- 생산계획 번호와 구매 요청 연결
- 협력회사에 견적 요청 전달
- 협력회사가 제출한 견적 조회
- 거래조건 확정과 계약 등록
- 업체 선정 후 구매 발주 전달
- 진척검수 일정·제작진척·납기진도·보완사항 관리
- 협력회사의 제작·출하 상태 조회
- 자재부서의 입고 완료 API 신호 조회

## 연결 대상

- 팀원 1: 구매부서 권한과 협력회사 번호
- 팀원 2: 생산계획, 부족 자재·수량, 필요일
- 팀원 4: 견적 제출, 발주 확인, 출하, 입고 결과

## 완료 기준

- [ ] 부족 자재로 조달계획을 생성한다.
- [ ] 협력회사는 자기 요청만 조회한다.
- [ ] 출하 상태가 구매 진척 화면에 표시된다.
- [ ] 입고 완료 신호가 발주 마감 조건에 연결된다.
