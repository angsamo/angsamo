# 3주차 — 팀원 2 개발·생산

## 이번 주 목표

생산 자재 부족분을 구매부서에 전달하고 불출 요청을 자재부서와 연결한다.

## 해야 할 일

- 팀원 4의 품목별 현재고 조회
- 자재 소요량에서 부족 수량 계산
- 부족 자재·수량·필요일을 구매부서에 전달
- 생산계획 번호와 구매 요청 연결
- 재고가 있는 자재의 불출 요청 생성
- 구매 처리 상태와 자재 출고 결과 조회

## 계산 규칙

```text
구매 필요 수량 = 필요 자재 수량 - 사용 가능 재고
```

## 연결 대상

- 팀원 1: 생산부서 수정 권한
- 팀원 3: 부족 자재, 수량, 생산계획 번호, 필요일
- 팀원 4: 현재고, 불출 요청, 출고 결과

## 완료 기준

- [ ] 부족 자재가 자동 계산된다.
- [ ] 구매부서가 부족 자재를 조회한다.
- [ ] 자재부서가 불출 요청을 조회한다.
- [ ] 연결 기능을 통합 브랜치에서 테스트했다.
