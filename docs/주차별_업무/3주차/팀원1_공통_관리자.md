# 3주차 — 팀원 1 공통·관리자

## 이번 주 목표

각 파트에 로그인·부서·협력회사 권한을 적용한다.

## 해야 할 일

- 로그인한 부서에 맞춰 메뉴 표시
- 자기 부서의 등록·수정·삭제 허용
- 다른 부서 원본 데이터는 차단하고 승인·공유 대시보드·자동 API 결과만 허용
- Controller와 API에서 부서 권한 검사
- 협력회사에 `vendorId` 조회 조건 적용
- 관리자 전체 조회 허용
- 팀원 2·3·4의 권한 처리 검토

## 연결 확인

| 팀원 | 확인할 내용 |
|---|---|
| 팀원 2 | 개발·생산 사용자 부서 코드 |
| 팀원 3 | 구매 사용자만 발주 수정 |
| 팀원 4 | 회사별 견적·발주 제한과 자재 권한 |

## 완료 기준

- [ ] URL을 직접 입력해도 권한 없는 기능은 차단된다.
- [ ] 다른 부서 데이터는 수정할 수 없다.
- [ ] 협력회사는 자기 회사 데이터만 본다.
- [ ] 관리자는 전체 데이터를 조회한다.
