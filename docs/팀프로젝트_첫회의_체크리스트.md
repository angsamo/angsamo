# 앙사모 ERP 팀 프로젝트 첫 회의 체크리스트

## 회의 목표

오늘 회의에서는 세부 코딩보다 프로젝트 범위, 역할, 공통 규칙과 첫 주 작업을 확정한다.

회의 종료 전 다음 결과물이 반드시 있어야 한다.

- [ ] 팀원 4명의 담당 파트 확정
- [ ] 1차 구현 범위 확정
- [ ] 공통 DB와 용어 확정
- [ ] GitHub 작업 방식 확정
- [ ] 1주차 개인별 작업 확정
- [ ] 다음 통합·점검 날짜 확정

## 3. 권한 규칙

### 역할 코드

- [ ] `MASTER`: 최고 관리자
- [ ] `DEPARTMENT_MANAGER`: 부서 관리자
- [ ] `WORKER`: 일반 업무자
- [ ] `SUPPLIER`: 외부 협력회사

### 접근 원칙

- [ ] 관리자는 전체 업무를 조회할 수 있다.
- [ ] 내부 사용자는 자기 부서 업무만 등록·수정한다.
- [ ] 협력회사는 자기 `vendor_id` 데이터만 조회·처리한다.
- [ ] 다른 부서 원본 목록과 상세 화면은 직접 열지 않는다.
- [ ] 화면 버튼뿐 아니라 Controller·Service·Mapper에서도 권한을 검사한다.

### 부서 간 데이터 공유 방식

- [ ] 승인 워크플로우
- [ ] 공유 대시보드
- [ ] 자동 API

연결 예시:

```text
생산 부족 자재 → 구매요청/API → 구매부서
생산 불출요청 → 승인 워크플로우 → 자재부서
정상 입고 완료 → API 신호 → 구매부서 발주 마감
```

- [ ] 작업 시작 전에 Pull 하기
- [ ] 작업 종료 전에 테스트·Commit·Push 하기

- [ ] `수정`, `aaa`, `작업함` 같은 메시지 사용하지 않기
