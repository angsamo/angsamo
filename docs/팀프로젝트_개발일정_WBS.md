# 앙사모 ERP 팀 프로젝트 개발 일정표(WBS)

## 1. 일정 개요

- 개발 기간: 2026년 8월 3일(월) ~ 8월 28일(금)
- 팀원: 4명
- 작업일: 평일 기준 20일
- 개발 방식: 기능 브랜치에서 동시 작업 후 정해진 날짜에 통합
- 목표: 부서별 핵심 CRUD와 조달·구매 업무 흐름 완성

## 2. 담당 파트

| 담당자 | 담당 영역 | 주요 기능 |
|---|---|---|
| 팀원 1 | 공통·관리자 | 로그인, 권한, 사용자, 부서, 협력회사 기본정보 |
| 팀원 2 | 개발·생산 | 품목, BOM, 생산계획, 자재 소요량, 불출 요청 |
| 팀원 3 | 구매 | 조달계획, 견적, 계약, 구매 발주, 진척검수, 발주 마감 |
| 팀원 4 | 자재·협력회사 | 협력회사 견적·출하, 입고, 재고, 출고, 반품 |

## 3. 브랜치 구성

```text
main
├── feature/admin
├── feature/development-production
├── feature/purchase
└── feature/material-supplier
```

`main` 브랜치에는 직접 작업하지 않고 각자의 기능 브랜치에서 작업한다.

## 4. 1주차: 공통 설계와 개발 준비

### 8월 3일(월) — 프로젝트 규칙 결정

#### 전체 팀

- 요구사항과 부서별 업무 범위 확인
- 담당 파트 최종 결정

## 10. 최종 통합 테스트 시나리오

1. 관리자가 사용자, 부서, 협력회사를 등록한다.
2. 개발부서가 완제품과 BOM을 등록한다.
3. 생산부서가 생산계획을 등록한다.
4. 필요한 자재와 부족 수량을 계산한다.
5. 구매부서가 부족 자재의 견적을 요청한다.
6. 협력회사가 견적을 제출한다.
7. 구매부서가 업체를 선정하고 발주한다.
8. 협력회사가 제작 상태를 변경하고 출하한다.
9. 자재부서가 입고 검수하고 재고를 증가시킨다.
10. 생산부서가 자재 불출을 요청한다.
11. 자재부서가 출고하고 재고를 감소시킨다.
12. 생산부서가 자재를 수령하고 생산을 진행한다.
13. 별도 입고 건에 불량을 등록해 반품과 재출하를 확인한다.
